🖼 图片转 PDF

多张图片合并成一个 PDF 文件，支持排序、纸张尺寸选择

📢 广告位 — Google AdSense
使用说明 · 点击展开

🎯 怎么用？
上传多张图片 → 拖拽调整顺序 → 选纸张尺寸 → 点「下载PDF」→ 一键保存。

📐 尺寸选择：
A4 — 图片适配到 A4 纸张（210×297mm），适合打印
原图尺寸 — 每页按图片原始像素尺寸，适合电子存档

🔒 安全性：所有处理完全在浏览器本地完成，图片绝不上传服务器。

📝 支持格式：PNG / JPG / WebP / BMP / SVG
